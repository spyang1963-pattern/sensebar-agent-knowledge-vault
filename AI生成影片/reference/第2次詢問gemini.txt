# 需要先安裝相依套件：pip install diffusers transformers accelerate torch

from diffusers import StableDiffusionPipeline
import torch

# 1. 檢查是否有可用的 GPU 設備
device = "cuda" if torch.cuda.is_available() else "cpu"

# 2. 載入預訓練的動漫風格或通用 Stable Diffusion 模型
model_id = "runwayml/stable-diffusion-v1-5"  # 也可以替換為特定動漫模型
pipe = StableDiffusionPipeline.from_pretrained(
    model_id, torch_dtype=torch.float16 if device == "cuda" else torch.float32
)
pipe = pipe.to(device)

# 3. 根據圖片內容與風格設計的提示詞 (Prompt)
prompt = (
    "2D webtoon style, anime illustration, interior scene, a young woman sitting"
    " on a green sofa, a little boy standing in front of the sofa, background"
    " window showing a modern city skyline with tall buildings, clean lines,"
    " vibrant colors, masterwork, high quality"
)

negative_prompt = (
    "photorealistic, 3D render, low quality, blurry, bad anatomy, deformed"
)

# 4. 執行生成
image = pipe(
    prompt=prompt,
    negative_prompt=negative_prompt,
    height=512,
    width=768,
    guidance_scale=7.5,
).images[0]

# 5. 儲存生成的圖片
image.save("generated_cartoon_image.png")
print("圖片已成功生成並儲存！")

第一步：掌握該風格的關鍵提示詞（Prompt Engineering）
AI 能否畫出對味的風格，關鍵在於提示詞的描述。這類畫風在 AI 領域通常會結合「網絡漫畫（Webtoon）」、「手機遊戲美術（Mobile game art）」與「誇張搞笑（Humorous cartoon）」的關鍵字。

A 2D webtoon style humorous cartoon illustration, Chinese mobile puzzle game art style. An indoor living room scene with a young woman sitting on a sofa and a boy standing in front. Clean outlines, flat shading, vibrant cartoon colors, exaggerated funny facial expressions, masterwork, high quality.

第二步：選擇適合的 AI 工具與平台
根據您的需求（是否要用程式控制或直接生成），您可以選擇以下幾種最佳途徑：

四、 進階技巧：如何保持角色與場景的一致性
若您希望產出連續的漫畫或多張相同主角的圖片，單靠文字描述常會讓角色外貌改變，可以加入以下技術：

固定 Seed（種子碼）：在程式中鎖定隨機亂數的 Seed 值，讓生成的畫面結構保持穩定。

ControlNet (Lineart / OpenPose)：上傳參考圖片的骨架或輪廓線，強制 AI 按照該構圖來畫，確保人物站姿與房間視角不走樣。

LoRA 微調模型：針對特定角色收集約 15 至 20 張截圖來訓練專屬微調模型，後續就能在提示詞中隨時召喚同一個主角。
