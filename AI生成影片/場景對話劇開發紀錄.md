# 樂之「場景式對話劇」開發紀錄（AI 生成影片）

> 本檔記錄「把樂之短影音從『半身對坐播報員』升級成『像看戲的活場景』」這條路的探索歷程、踩坑與定案做法，供接手者快速掌握。最後更新：2026-10-23。

---

## 1. 目標與背景

- **痛點**：既有 `make_comic.py`＝半身對坐、固定左右、只換表情，像播報員，呆板無吸引力。
- **想要的**：全身有手腳的角色、立體透視空間、活背景（掛鐘秒針／窗外樹雲／咖啡熱氣）、開場進場演出，畫風朝「中國搞笑手遊／腦洞解謎／2D 網漫風」，但角色要**怪奇好笑、有特點**（非制式帥哥美女）。
- **設計原則（使用者拍板，務必遵守）**：
  1. **「特殊、不在正常眼光下的設計」反而是賣點**——角色怪奇／好笑／非標準比例是特色，不要「正常化」成制式比例。
  2. **每版產物放獨立資料夾、不覆蓋**（供逐版比較）。

## 2. 路線探索歷程（四條路，各自結論）

### 路線 A：純程式「手畫 2D 透視」（`make_scene.py` v1~v6）❌
- 用 PIL 手畫三面空間（後牆＋地板＋左牆）、線條平行垂直、消失點可控。
- **結論：失敗**。反覆被退：地板線像「一望無際」、地毯/家具邊不平行＝視覺矛盾、人物一前一後的臉/後腦呈現難。

### 路線 B：3D 投影引擎（`make_scene.py` 現行核心）⚠️
- 用 `Camera(eye, target, fov).project()` 把房間/家具/人物的 3D 座標投影到 2D，透視自動正確。
- 支援 `draw_box`（Y 軸旋轉 yaw、背向面剔除）、`draw_sofa`（底座＋椅背）。
- **結論**：透視數學對了（可當基礎），但角色怪奇度/品質不足、椅子像光禿箱子，最終沒走這條。

### 路線 C：純 AI 生圖（Pollinations flux）❌（角色部分）
- 生角色、場景、背景都試過（`working/ai_style_test`、`ai_collab*`、`ai_bg*`）。
- **關鍵結論（重要陷阱）**：
  1. **flux 有頑固的「俊男美女」偏見**：`chibi / ugly-cute / caricature / NOT handsome` 等關鍵詞都拉不回怪奇特點；加「漫畫式、有特點、不要制式、可以誇張」也只是從帥哥變「粗曠帥哥」。
  2. **複雜構圖指令不聽**：要「兩人物＋茶几＋窗＋鐘」會漏（人物跑掉、缺茶几）。
  3. **三表情表情集（character sheet）只是同一張臉換角度，非換表情**。
  4. **解析度上限約 576×1024**（要求 1080×1920 也只回這個），放大會糊。
  5. Pollinations 偶發 402，重試後會成功。
- **Gemini 建議**（`reference/第2次詢問gemini.txt`）：這類網漫風要用 AI 生圖，關鍵詞 `2D webtoon style, humorous cartoon, mobile game art, clean vector-like line art, flat shading, vibrant colors`；工具 Midjourney/DALL-E 3（付費）或 Stable Diffusion + `animagine-xl-3.1`（需 GPU，本機 MX130 跑不動）。

### 路線 D：融合版（最終定案）✅
- **AI 生背景（空間感）＋ 程式畫怪奇角色（特點）＋ 程式合成/動態**。
- 完整鏈條已跑通，見 §4。

## 3. 純 AI 生短影片的路徑（未完成，僅記錄做法）

> 我們只做到「生角色＋生背景」，**沒有完成一支完整的純 AI 短影片**。若接手者要走這條，路徑如下：

1. **生角色定裝照**：固定 `seed` + 詳盡人設 prompt（大眼鏡、呆毛、紅帽、配色），多次生成直到接受。
2. **生背景空景**：`2D flat vector cartoon, NO shading, NO realistic, empty living room, two sofas facing each other, coffee table, window, clock, NO people`。
3. **程式合成**：把角色貼到背景（位置程式控制）。
4. **動態**：對嘴/眨眼/運鏡仍用程式做。
- **注意**：純 AI 生角色這條路的死結就是 flux 拉不出「怪奇特點」，除非改用付費生圖或本機 SD（無 GPU）。

## 4. 融合版完整鏈條（定案做法，接手者照抄）

### 4.1 角色畫法（`draw_char_seated`）
- **姿勢**：盤腿坐、側身（`dir=+1` 面向右、`-1` 面向左）。
- **下半身**：屁股＋大腿＝單一 `rounded_rectangle`（`hip_back = sx - dir*0.9r`、`hip_front = sx + dir*1.6r`，取 min/max），**單一外框**（避免交接線）；前側加一小截鞋（暗示盤腿）。
- **頭髮**：用 **`chord`（不是 `pieslice`！）** `chord(bbox, 217, 323)`，只蓋頭頂約 1/5，露出額頭與眉毛。
  - ⚠️ **陷阱**：`pieslice` 會把圓心一起填滿，頭髮一路蓋到中心、把眉毛遮住；一定要用 `chord`（弧＋弦＝頭頂蓋子）。
- **側臉五官位置**（頭圓心 `(sx,sy)`、半徑 `r`）：
  - 眼：`(sx + dir*0.42r, sy + 0.12r)`，單眼（側面）。
  - 眉：`ey - 0.42r`（在髮線下方、露出）。
  - 鼻：`(sx + dir*0.72r, sy + 0.12r)` 小凸起。
  - 嘴：`(sx + dir*0.4r, sy + 0.5r)`。
- **特點**：阿忍＝大圓眼鏡＋黑側分髮＋鼠尾草綠衣；小樂＝紅帽＋棕髮＋橘衣。

### 4.2 表情系統（`draw_head` 參數化）
- **眼** `eye`：`normal`（點）／`blink`（橫線）／`wide`（白眼＋瞳）。
- **眉** `brow`：`flat`／`up`（上揚）／`in`（皺）。
- **嘴** `mouth`：`closed`（線）／`half`（小橢圓）／`open`（大橢圓）／`smile`（弧）。
- 循環範例：正常說話 → 驚喜（瞪眼揚眉）→ 擔憂（皺眉）→ 開心（微笑）；眨眼每 3 秒一次。

### 4.3 真實對嘴
- `make_dialog.md._tts(text, voice, mp3)` 做 TTS（`VOICE = {'ren':'zh-TW-YunJheNeural','le':'zh-TW-HsiaoYuNeural'}`）。
- `make_comic.mc._energy(mp3, fps, nframes)` 解碼 mp3 → 每幀 RMS 音量包絡。
- 音量→嘴型三階：`e<0.15`=closed、`<0.5`=half、`>=0.5`=open。
- 說話者嘴動＋眨眼，聆聽者嘴閉＋偶爾眨眼。

### 4.4 進場動畫（`draw_char_standing`）
- 站姿：頭＋身體＋兩腿（`sy+2.5r`→`sy+4.6r`）＋一隻外側手臂（**有描邊＋膚色手**）。
- 手臂：平常下垂 `(shx, shy)→(shx+dir*0.2r, shy+1.3r)`；揮手舉起 `hy = shy - 2.4r`（舉到頭上方）＋左右擺動 `wa = sin(t*8)*16`。
- 時間軸：走路進場（x 從畫面右緣→椅子位置）→ 揮手 → 坐下（切盤腿坐姿）。

### 4.5 合成與輸出
- AI 背景（`working/ai_bg3/hi_a.png`，576×1024）＋ 逐幀疊加程式角色。
- `encode()` 自訂編碼（因背景非 1080p，不能直接套 `mc.encode_frames` 的 1080×1920）。
- 串接：進場（靜音）+ 對白（`ms.concat_scenes` + `anullsrc` 靜音軌）。
- **字幕**：程式畫（`draw_subtitle`，PIL 黑條＋白字、固定置底、含說話者名字），**不要用 `subtitles` 濾鏡**。
- 完整 demo：`working/full_demo/full_demo_subs.mp4`。

## 5. 關鍵教訓（接手者必讀）

1. **位置最難調**：角色放到 AI 背景上，位置/大小/坐姿/前後關係，全部要人工反覆調（因為 agent 看不到背景的椅子確切位置）。**做法**：先出「純角色白底圖」讓使用者看角色本身 → 再合成 → 依回饋微調 x/y/大小。
2. **每版獨立資料夾**：`poc_scene_vN/`、`ai_compositeN/`，不覆蓋（使用者也明令）。
3. **`pieslice` vs `chord`**：頭髮要用 `chord`，否則蓋住眉毛。
4. **方向 bug**：`dir=-1`（面向左）時，屁股/腿/手的 `±dir` 都要跟著反，否則會「腿不見/蓋住」。
5. **交接線**：同材質（屁股＋腿）要畫成單一形狀、單一外框；鞋與腿交接處去描邊。
6. **flux 天花板**：怪奇拉不回、構圖不聽、解析度 576×1024。要更清楚→付費生圖或本機 SD（無 GPU）。
7. **TEMP 腳本不持久**：最終可用腳本散在 `C:\Users\hpspy\AppData\Local\Temp\opencode\`（`full_demo.py`、`lipsync_demo.py`、`face_anim.py`、`ai_composite4.py` 等），**接手者應把它們收進專案**。
8. **字幕別用 ffmpeg 的 `subtitles` 濾鏡**：SRT→ASS 的換行/定位不可控，兩句長度不同就高度不一致。**改用程式直接畫字幕**（PIL 畫黑條＋白字，`draw_subtitle`），位置完全可控、固定置底、保證一致。
9. **「說的話」與「顯示的字幕」要分開**：加說話者名字（「阿忍：」）時，若同一段文字同時拿去 TTS 配音，聲音會把「阿忍」也唸出來。**TTS 用純台詞、字幕用 `名字：台詞` 兩者分離**。
