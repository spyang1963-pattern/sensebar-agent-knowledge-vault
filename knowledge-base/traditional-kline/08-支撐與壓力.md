# 支撐與壓力

## 支撐判斷

### K棒支撐
- 紅黑紅的**黑K低點** = 支撐
- 突破關卡那根K棒的低點 = 支撐
- 黑K低點不破 = 真突破

### 關卡支撐
- 上漲後回檔形成的轉折低點 = 關卡
- 突破關卡後，關卡變支撐

### 均線支撐
- 10MA = 移動式停利線
- 跌破10MA → 考慮出場

## 壓力判斷

### 平台壓力
- 前波高點 = 壓力
- 突破壓力 = 關卡突破

### 頸線壓力
- 下跌後反彈形成的轉折高點 = 頸線
- 突破頸線 = 翻多訊號

## 突破判斷
> 「突破頸線那根K棒的低點如果沒有跌破，就做真突破。」

## 支撐壓力互換
- 壓力被突破 → 變成支撐
- 支撐被跌破 → 變成壓力
