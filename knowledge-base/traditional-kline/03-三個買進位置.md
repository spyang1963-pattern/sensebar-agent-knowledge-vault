# 三個買進位置

## 核心原則
> 「我的買進位置就只有三個：底部區、行進間、轉讓區。其他位置我都不買。」

## 三大買進位置

### 1. 底部區
- **條件**：長期觀察的股票才找得到底部區
- **方法**：K線型態判斷
- **優勢**：風險最低，報酬潛力最大
- **例子**：在底部區買進，等噴出後獲利

### 2. 行進間
- **條件**：電腦選股選到（如 DIF < 0 的股票）
- **方法**：指標選股 + K線型態確認
- **例子**：紅黑紅突破關卡時進場

### 3. 轉讓區
- **條件**：電腦選股、別人問、自己注意的股票
- **方法**：K線型態判斷
- **特性**：轉浪行為，後續有機會噴出

## 不買的位置
- **滿足區**：絕對不買
- **反彈區**：不買（「我幹嘛去買反彈？不如去買底部區還比較安全」）

## 選股流程
1. 電腦選股（DIF < 0 等條件）→ 選出多檔
2. 看潮汐位置
3. 回到周線看支撐
4. 縱橫研判 → 挑最有機會的一檔

> 「DIF小於0，你電腦選股選出來，今天選出20檔，你要挑哪一檔？潮汐的位置看完之後，再去回到周線去看它的支撐等等，縱橫研判，挑這檔比較有機會。」
