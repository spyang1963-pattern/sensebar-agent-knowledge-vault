# 潮汐理論

## 定義
潮汐理論是判斷股價大輪廓的工具，用來確認目前走勢在整體趨勢中的位置。

## 三個潮汐

### 潮汐1
- 第一段上漲
- 通常是底部起漲的第一波

### 潮汐2
- 回檔修正
- 谷底不能比前低更低（否則趨勢改變）

### 潮汐3
- 噴出波
- 通常是最強的一段
- 潮汐3噴完後 → 進入修正

## 潮汐判斷規則
1. 未來高點比前高高 → 多頭確認
2. 谷底比前低高 → 多頭確認
3. 潮汐3噴完 → 後面是修正，不要追

## 潮汐與操作
- 潮汐1 → 觀察
- 潮汐2 → 找買點（底部區）
- 潮汐3 → 持股 + 設停利
- 潮汐3噴完 → 出場

## 重要觀念
> 「潮汐噴完了，後面就是修正。縱使後面再漲，頂多也是陌生浪。」

## 潮汐與K線型態
- 在潮汐3的位置出現紅黑紅 → 有機會噴出
- 在反彈坡的位置出現紅黑紅 → 只是完成反彈，不要期待太高
