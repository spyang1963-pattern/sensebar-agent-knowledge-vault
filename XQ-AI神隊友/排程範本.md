# 排程範本（Routines）

Claude Code 桌面版可以設「排程」：固定時間自動執行一段指示。
下面三段話照抄，把 `C:\Users\你\Desktop\XQ-AI神隊友` 換成你實際放套件的路徑（檔案總管網址列可以複製）。

兩種建法都可以：
- **方式 A**：左側選單 → Routines → 把整段貼進「What do you want automated?」→ Draft routine → 確認後啟用
- **方式 B**：在 XQ-AI神隊友 的對話裡貼同一段，開頭加「幫我建一個排程：」

建好之後在 Routines 頁面會看到：
`Repeats ~At 0 and 30 minutes past the hour, between 09:00 AM and 01:59 PM, Monday through Friday`
（這就是 cron `0,30 9-13 * * 1-5`。09:00 那一次會被腳本的時段守門擋掉，實際跑 09:30～13:30 共九次。）

---

## 範本一：三個都跑（建議）

```
週一到週五 09:00 到 13:30，每 30 分鐘執行一次（cron：0,30 9-13 * * 1-5）。
排程名稱 xq-intraday-loop。
每次執行時：先讀取 C:\Users\你\Desktop\XQ-AI神隊友\CLAUDE.md，
依照裡面的「共同流程」依序跑作法一（族群資金排行）、作法二（齊漲分歧診斷）、作法三（盤中觀察三段），
各自把報告存到 routines\outputs。
如果 snapshot.ps1 回報 SKIP=1 或 stale=1，就跳過、不寫報告；
抓不到 Excel 就在對話裡說明原因，不要用舊快照頂替、不要編造數字。
```

## 範本二：只跑其中一個

把範本一的「依序跑作法一、作法二、作法三」改成你要的那一個，排程名稱改成 `xq-rank-loop`／`xq-breadth-loop`／`xq-notes-loop`，其他不變。

## 範本三：只要收盤那一輪

```
週一到週五 13:45 執行一次（cron：45 13 * * 1-5）。
排程名稱 xq-close-loop。
每次執行時：先讀取 C:\Users\你\Desktop\XQ-AI神隊友\CLAUDE.md，依照裡面的「共同流程」依序跑作法一、二、三，
各自把報告存到 routines\outputs；盤中觀察三段優先用「本次與前一份快照相減＝尾盤集合競價」的角度寫。
snapshot.ps1 回報 stale=1 就跳過；抓不到 Excel 就說明原因，不要編造數字。
```

## 加上推播（選配，有 Telegram 外掛才加）

在任一範本最後加一行：

```
報告寫完後，依 CLAUDE.md「推播設定」的格式把摘要發到 Telegram chat_id ○○○（format 用 text）。
```

---

## 注意事項

- **三樣東西要開著**：電腦（不要睡眠）、Claude Code 桌面版、Excel 裡的 XQ 報價表。關掉時到期的排程不會跑，會等下次打開 app 補跑一次。
- **每次執行都是全新的對話**，它不記得你之前講過什麼，所以範本開頭才要它先讀 CLAUDE.md。
- 想暫停：「把 xq-intraday-loop 停用」；想改時間：「改成每 20 分鐘」（cron `*/20 9-13 * * 1-5`）。也可以在 Routines 頁面直接關掉。
- cron 五個欄位是「分 時 日 月 星期」，用你電腦的本地時間。常用：`0,30 9-13 * * 1-5`（每 30 分）、`*/20 9-13 * * 1-5`（每 20 分）、`45 13 * * 1-5`（每天 13:45 一次）。
