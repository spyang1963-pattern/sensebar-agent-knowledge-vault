# XQ-AI神隊友｜開始使用

讓 AI 幫你看完看不完的盤。
這包東西做的事只有一件：**把你每天盤中固定要看的三件事，變成固定的作法，交給 Claude Code 每天固定做。**

| 作法 | 回答的問題 | 跟 AI 說這句就好 |
|---|---|---|
| 一、族群資金排行 | 今天錢流到哪個族群？ | 「跑族群資金排行」 |
| 二、齊漲分歧診斷 | 這個族群是整組在動，還是只有一檔在動？ | 「跑齊漲分歧」 |
| 三、盤中觀察三段 | 跟上一個時段比，盤面變了什麼？ | 「跑盤中觀察」 |

三個一起跑就說「三個都跑」。

> **有圖的完整版**：雙擊同資料夾的 `圖解教學.html`，從安裝、接 XQ、第一次執行、設排程到程式碼介紹，一步一圖。下面是文字版快速開始。

---

## 一、你需要準備的

1. Windows 10／11 + Excel（桌機版）
2. XQ 全球贏家（報價表要能用「輸出欄位 → DDE」貼到 Excel）
3. Claude Code（到 https://claude.com/claude-code 下載安裝；要有 Claude 帳號）

沒有寫程式能力也可以。全部操作都是「打開 Excel」「跟 Claude Code 講一句話」。

---

## 二、安裝（只做一次，五步）

1. **解壓縮**，把 `XQ-AI神隊友` 整個資料夾放到你喜歡的地方（桌面、D 槽都可以，路徑有中文、空格都沒關係）。裡面的資料夾名稱**不要改**（尤其 `routines`）。
2. **打開 XQ 報價表**：XQ → 自動選股（例如「成交額前 500」）→ 在報價表上開「輸出欄位」→ 把要的欄位勾起來 → 「選擇即時資料伺服器」選 **DDE 伺服器** → 確定 → 貼到 Excel。Excel **不用存檔**，放著就好，每一格都會跟著 XQ 跳。
   - 一定要有的欄位：代碼、商品、成交、漲幅%、總量、委買、委賣、均價、股本、成交值。建議再加「內外盤比」。
3. **雙擊 `安裝檢查.bat`**，看到「全部 OK」就可以。有 `[NG]` 的話照它說的處理（最常見：Excel 沒開、欄位沒勾）。
4. **打開 Claude Code，切到這個資料夾**。最簡單的方式：在資料夾空白處按右鍵 → 「在終端機中開啟」→ 輸入 `claude` 按 Enter。（或在 Claude Code 裡輸入 `cd` 加上這個資料夾的路徑。）
5. 跟它說：**「檢查環境」**。它會跑一次檢查並用白話告訴你結果。

裝好了。之後每天只要做第 2 步（讓 Excel 開著）和第 4 步（打開 Claude Code）。

---

## 三、每天怎麼用

- **什麼時候跑**：盤中 09:25–13:55，每 20 到 30 分鐘跑一輪；13:30 收盤後再跑一輪（那一輪可以看到尾盤集合競價的錢砸在哪）。
- **怎麼跑**：跟 Claude Code 說「跑族群資金排行」「跑齊漲分歧」「跑盤中觀察」，或「三個都跑」。
- **它會做什麼**：從 Excel 抓一份快照存起來 → 跑分析腳本 → 寫一份報告存到 `routines\outputs\`，檔名就是時間，例如 `20260820_1336_族群資金排行.md`，並在對話裡貼出重點。
- **非盤中想測試**：說「強制跑一次族群資金排行」（它會加 `-Force`，報告會標明是測試）。

報告長什麼樣，先看 `範例報告\` 裡的三份，那是實際跑出來的。

### 讓它自己跑（排程）

Claude Code 桌面版左側選單有 **Routines**（排程）。把 `排程範本.md` 裡的那段話貼進去（路徑換成你的），它就會週一到週五 09:00–13:30 每 30 分鐘自己跑一輪，Routines 頁面會顯示：

`Repeats ~At 0 and 30 minutes past the hour, between 09:00 AM and 01:59 PM, Monday through Friday`

排程要跑，三樣東西要開著：電腦（不睡眠）、Claude Code、Excel 裡的 XQ 報價表。詳見 `排程範本.md` 與 `圖解教學.html` 第 08 節。

## 四、想改東西，直接跟 Claude Code 講

這套東西的設計是：**你不用開程式碼，跟它講就好。** 它知道每樣東西放在哪裡（都寫在 `CLAUDE.md` 裡）。幾個常見的：

| 你想要 | 跟它說（照抄就行） |
|---|---|
| 補族群分類 | 「把 3167 大量、8021 尖點歸到 PCB鑽孔設備耗材，然後重跑齊漲分歧看判定有沒有變」 |
| 改判定門檻 | 「齊漲的門檻從 75% 改成 80%，改完跑一次給我看差在哪」 |
| 改盯的個股 | 「盤中觀察每次固定盯的個股加上 2317 鴻海、拿掉 3653」 |
| 改報告長相 | 「族群資金排行的反差提醒每次最多列三檔就好，太長了」 |
| 改時段 | 「盤中時段守門改成 09:05 到 13:35」 |
| 加第四個作法 | 「我每天還會看一個東西：成交值前 100 名裡換手率最高的 20 檔，幫我做成第四個作法」 |
| 推到手機 | 「我有裝 Telegram 外掛，chat_id 是 ○○○，以後報告寫完順便推一份摘要給我」 |

它會先說要改哪個檔、會影響什麼，再動手，改完跑一次驗證。你看結果就好。

如果你想自己動手，東西在這裡：

| 檔案 | 放什麼 |
|---|---|
| `routines\groups.ps1` | 代碼 → 族群 對照表。**整套工具裡唯一要你長期維護的檔案**。每次分析末尾會列「未分類」，照著補 |
| `routines\groups_extra.ps1` | 你自己的補充分類（選用）。寫在這裡的不會被新版 `groups.ps1` 蓋掉 |
| `routines\analyze_breadth.ps1`、`analyze_notes.ps1` 開頭 | 判定門檻（齊漲比例、±3% 分歧、9.5% 漲停、10% 換手…），一行一個，有註解 |
| `routines\snapshot.ps1` 開頭 | 盤中時段守門（565／835 是分鐘數 = 09:25／13:55） |
| `CLAUDE.md` | 三種報告的規格、觸發語、鐵則。想改報告寫法就改這裡 |

用記事本改 `.ps1` 的話，另存新檔時編碼請選「UTF-8 (含 BOM)」，不然中文會亂碼、腳本會跑不動。

## 五、怎麼跟 AI 講，它才會穩定給你一樣的東西

同一句話今天問明天問，AI 會給不同答案；但**同一份 SOP 每天跑，它就給一樣格式的東西**，今天才能跟昨天比。

寫 SOP 只要講三件事：

1. **資料從哪來**：哪個檔案、有哪些欄位
2. **要算什麼**：排序、加總、分類、跟誰比
3. **輸出什麼格式**：表格？三段結論？存成檔案？

可以照抄的一句（這就是作法一的原型）：

> 我有一份報價快照 CSV，欄位有代碼、名稱、漲跌幅、成交值、換手率。幫我取成交值前 50 名，每一檔貼上族群標籤，依族群加總金額排序，標出各族群的漲跌家數，最後寫一段結論說今天錢最集中在哪個族群。輸出成表格，存成檔案。

講不清楚沒關係：先講一次讓它做，錯了再說哪裡錯。這個過程就是在寫 SOP。寫穩了，之後每天就是機器人在跑。

## 六、常見問題

**Q：它說「找不到執行中的 Excel」**
A：Excel 沒開，或開的不是 XQ 貼過來的報價表。回到「安裝」第 2 步。

**Q：它說「Excel 忙碌」「按 Esc」**
A：Excel 裡有儲存格正在編輯狀態。切到 Excel 按一下 Esc，再跟它說「再跑一次」。

**Q：它說「找不到報價工作表」，但 Excel 明明開著**
A：多半是前一天殘留的 Excel 視窗（沒有活頁簿）。把 Excel 全關掉，重新從 XQ 貼一次。

**Q：它說「SKIP=1 非盤中時段」**
A：正常。現在不是 09:25–13:55。要測試就說「強制跑」。

**Q：它說「stale=1 資料沒變」**
A：這次抓到的和上一份一模一樣，通常是休市、XQ 斷線、或 Excel 停住了。確認 XQ 報價有在跳再跑。

**Q：報告最後有一串「未分類」**
A：這些股票還沒有族群。跟它說「把 ○○ 歸到 ○○」就好，或自己補進 `routines\groups.ps1`。分類越完整，齊漲／分歧的判定越準（漏了中小型成員會把族群齊漲誤判成一檔獨走）。

**Q：可以不用 Claude Code 嗎？**
A：腳本本身不挑工具，ChatGPT、Gemini 都能照 `CLAUDE.md` 的規格幫你寫報告；但「從 Excel 抓快照、跑腳本、寫檔案」這段要工具能在你電腦上做事。這包是以 Claude Code 為準做的。

**Q：我沒有 XQ，但有別的看盤軟體能匯到 Excel**
A：只要 Excel 裡的表第一列有「代碼、商品、成交、漲幅%、總量、委買、委賣、均價、股本、成交值」這些標題，腳本就吃得到。欄位名不同的話，跟 Claude Code 說「我的報價表欄位叫 ○○，幫我對應」。

## 七、資料夾結構

```
XQ-AI神隊友\
├─ 圖解教學.html        ← 有圖的完整教學（雙擊打開）
├─ 開始使用.md          ← 你現在在看的
├─ 排程範本.md          ← 設排程時照抄的提示詞
├─ CLAUDE.md            ← 給 Claude Code 看的 SOP（它打開這個資料夾就會自動讀）
├─ 安裝檢查.bat         ← 雙擊檢查環境
├─ routines\
│   ├─ snapshot.ps1     ← 從 Excel 抓快照
│   ├─ analyze_rank.ps1     ← 作法一 計算
│   ├─ analyze_breadth.ps1  ← 作法二 計算
│   ├─ analyze_notes.ps1    ← 作法三 計算
│   ├─ groups.ps1       ← 族群分類表（你維護）
│   ├─ groups_extra.ps1 ← 你的補充分類（選用）
│   ├─ check_env.ps1    ← 安裝檢查
│   ├─ _excel.ps1       ← 掛 Excel 的共用模組（不用動）
│   ├─ snapshots\       ← 快照 CSV 會累積在這
│   └─ outputs\         ← 報告會存在這
└─ 範例報告\
    ├─ 20260820_1336_族群資金排行.md
    ├─ 20260820_1341_齊漲分歧診斷.md
    ├─ 20260820_1342_盤中觀察三段.md
    └─ 範例快照\        ← 四份真實快照，可拿來測試分析腳本
```

---

本套件為個人工作流程分享。所有報告只描述盤面事實與資金結構，不構成任何投資建議；投資有風險，請自行判斷。
