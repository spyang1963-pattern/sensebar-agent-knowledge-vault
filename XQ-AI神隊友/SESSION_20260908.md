**解決方案（你選的：「程式內自動取成交值前500」＋改用活頁簿1）**：

- 新增 `-KeepN N` 參數（預設 500）：存檔前依成交值排序取前 N，超過就裁掉。輸出旗標多 `kept=`。

- **`xq_snapshot_loop.bat` 中文註解問題**：批次檔含中文註解 + 中文路徑被 cmd 亂解 → LastTaskResult=1。

## 重要教訓（下次接手先記）

1. **大報價表一律分塊讀**：`_excel.ps1` 已內建（只抓標題列判定），`snapshot.ps1` 已內建 300 列分塊。
   不要回歸到「一次整表 Value2」。
2. **`-2146826246` 是 Int32 錯誤碼**：判「有效資料」要排除「數值型態且 <0」的欄位，不能只看 `--`／null。
3. **PowerShell 陷阱**：`$arr[$i+1, $j]`（索引內含運算式+逗號）會報錯 → 先算 `$r=$i+1` 再 `$arr[$r,$j]`。
4. **批次檔別放中文**：含中文註解＋中文路徑會被 cmd 亂解（LastTaskResult=1）→ 用英文註解。
5. **成交值單位**：XQ 欄位是「億」或「萬」字串，統一轉成「億」再排序。
6. **快照留要「有效值驗證」**：避免又存垃圾污染③比較（本次靠 KeepN+排除錯誤欄位達成）。
7. **內嵌 JSON 一定要轉義 `</`**（`.replace("</","<\\/")`）：完整 HTML fragment 自己含 `<script>`，不轉義就截斷 JSON。
8. **同輪快照只差幾秒**：rank/breadth/notes 各自 stamp 是「產生瞬間」的秒數；比歷史要按「分鐘」合併，否則時間軸每 30 分會冒出 3 個點。
9. **編輯長 JS 區段時別把函式頭吃掉**：`DASH_JS` 編輯曾誤把 `window.onload = function(){` 換成新函式，
   window.onload 消失、histbar 建置碼變成 `sortTable` 的 body（dash 整個不渲染）。改了必跑
   `py_compile`＋重產＋`check_dash.py`（驗證 round 數/JSON 未截斷）。
10. **配色語意固定「紅=多、綠=空」**（CSS `--up/--down`、`.key-red/.key-green`）；寫判讀文案時，
    「收黑/跌/流出/退潮/走弱」一律用綠，別再用紅色。
