# 金融報告格式範本（2026-09-07 定案）

> **本文件是每日報告與深度報告樣式的唯一基準。**
> 未來任一樣式走樣時，先對照此文件判定「哪裡偏離」，再修對應程式碼，最後用下方「產生與驗證流程」重產並驗證線上。不要憑記憶改樣式。
>
> 對應程式碼：`report_generator.py`（日報）、`deep_report.py`（深報）、`publisher/template.html`（CSS）。

---

## 一、每日報告（daily/*.html）

### 區塊順序（固定，不可互換）
1. `## 📅 行事曆排期事件`（今日／近期已排定事件；當日無排期才省略，其餘永遠出現）
2. `## 🆕 本次新增事件（置頂：最新產出）`（**永遠存在**；本次無新收錄事件時顯示「本次新增 **0 筆**（自上次產出 XX 以來）…」，區塊不可消失）
3. `## 市場行情快照`（code fence 表格＋「快照資料時間」註記；逾 24h 加 ⚠️）
4. `## 重大事件（severity ≥ 2）`
5. `## 分類彙整`
6. `## 全部事件`（標題式清單）

### 樣式
- 事件行格式：`- **[{時間戳}]** **{severity badge}[{類別}][{情緒}]** {標題}`
- **時間戳**：粗黑框起，`**[09-07 16:52]**`
- 影響／標的子項（重大事件、本次新增內）：`  - <strong style="color:#174ea6">影響</strong>: …`、`  - <strong style="color:#174ea6">標的</strong>: …`（**粗藍 `#174ea6`**，此色在日報環境辨識良好，勿改）
- severity badge：`_sev_badge`（帶底色徽章）
- 章節標題 `##`：左側粗藍邊（template h2）

## 二、深度報告（deep/*-pm.html）

### 章節標題
一律 `## 一、市場總覽` … `## 九、免責聲明`（h2、左藍邊）。**禁止 h3/h4/h5 標題塊**（`###`/`####` 會整成大字塊、拉開行距）。

### 章節樣式（次標一律「顏色區分層次」，全部頂格扁平、行距最小）
- **一、市場總覽**：次標黑粗（`<strong style="color:#000">`）。
- **二、行情快照**：次標黑粗；紅漲綠跌（`<span style="color:#c0392b">`▲、`<span style="color:#2e7d32">`▼）。每指數／匯率／原油／黃金／個股**單獨一列**。
- **三、數據決戰焦點**：焦點事件標題 **暗紅 `#b02020`**（整行無內容）；其下「最新公布之結果／對市場的即時影響／後續觀察點」**黑粗**（帶冒號內容）。
- **四、重大事件**：事件名稱 **暗紅 `#b02020`**（可帶縮排）；「事件核心／傳導路徑／關聯標的／未來一週走勢」**黑粗**。
- **五、跨日相關性**：主軸標題 **暗紅 `#b02020`**；「第一／二／三階段」**黑粗**；後續說明段落為一般黑字。
- **六、分類展望**：`股市／債市／匯市／商品（油金）／地緣政治` **展望**主標題 **暗紅 `#b02020`**；`短期展望（1週）／中期展望（1月）／長期展望（1季）` **黑粗**。
- **七、風險與機會**：`風險（警示）`、`機會（看好）` **暗紅 `#b02020`**；其後群組內各風險／機會項目 **黑粗**；`標的`、`理由`（精確兩字整行）**淺綠 `#4caf50`**。
  - **七章固定三層結構（SYSTEM_PROMPT 已鎖死，模型必須輸出）**：大分類標題 → `- **風險/機會名稱**`（頂格） → 兩空格縮排子項 `  - **標的**：…`、`  - **理由**：…`。若某一版七章沒有「標的／理由」子項＝模型沒照結構，不要改後處理，重產。
  - 「標的」「理由」是系統顯示關鍵字，精確兩字才上淺綠；四章的「關聯標的」是完整標題（黑），勿混淆。
- **八、操作建議摘要**：觀察重點標題一律 **暗紅 `#b02020`**；說明段落一般黑字。
- **九、免責聲明**：純文字。

### 間距（template.html，勿單獨改動其中一項）
- `article.card { line-height: 1.15 }`（列距）
- `article.card p { margin: 3px 0 }`
- `article.card ul, article.card ol { margin: 3px 0 6px; padding-left: 22px }`
- `article.card h2 { margin-top: 12px }`、`article.card h3 { margin-top: 10px }`
- `article.card blockquote { margin: 4px 0 }`、`article.card hr { margin: 12px 0 }`
- `article.card strong { font-weight: 700 }`（**不可全域染紅**，顏色一律 inline 控制）

## 三、後處理要領（deep_report.py）

`_colorize_focus_titles`（三/四章）＋`_flatten_heading_noise`（全篇扁平化）＋ `_flatten` 內「章節語意規則」（五~八層次）。重點：

1. **模型會吐多種標題形式**，全部要剝成扁平黑／紅／綠：
   `- **#### X**`、`- #### X`、`### X`、`#### X`、縮排子項 `  - **X**`、以及 `- **X**：`。
2. **層次不可只靠縮排**：模型每次輸出的縮排／標記隨機。判定順序＝章節語意規則優先，縮排其次（只當「黑」訊號，不再當主判）。
   - 六章：`^(短期|中期|長期)\s*[\(（]` → 黑
   - 七章：`風險(),機會（）`群組→紅；群組內項目→黑；`^(標的|理由)$`→淺綠 `#4caf50`
   - 其餘五~八頂格 `- **X**` → 紅（主層）
3. **顏色不可與黑混同**：深藍 `#174ea6` 在粗體黑之間的分辨度差（日報可用因字級不同）；深報內標籤用淺綠 `#4caf50`，焦點／主層用暗紅 `#b02020`。
4. 章節標題 `#{1,6} [一二三四五六七八九十]、` → 正規化為 `## `。

## 五、反覆重踩的陷阱（修樣式前必讀）
- **模型層次輸出每輪都隨機**：不要拿「本次輸出」當規格；以本文件語意規則為準。
- `- #### X`（無 `**` 包裹）與 `- **#### X**` 同時存在，剝除邏輯兩種都要寫。
- 七章「標的」與四章「關聯標的」不同：前者恰兩字整行→淺綠；後者是完整標題→黑。
- 六章標題有時「短期 (1週)」有時「短期展望（1週）」，正則兩式都要能命中。
- ＜span 紅綠漲跌＞在二章由模型輸出（prompt 要求），後處理勿覆寫。
